RAMOS ARIZPE AL DÍA — PUBLICACIÓN AUTOMÁTICA DE NOTICIAS

Sube estos 3 archivos a la RAÍZ del repositorio GitHub:
- build.js
- package.json
- netlify.toml

Después haz Commit directly to main.

Qué hará:
1. Netlify ejecutará automáticamente npm run build.
2. Las notas creadas en /admin se leerán desde content/noticias.
3. La nota marcada "Destacar en portada" ocupará el espacio principal.
4. Las noticias recientes aparecerán en "Últimas noticias".
5. Cada nota generará una URL propia.
6. Se crearán automáticamente sitemap.xml, news-sitemap.xml y robots.txt.

No cambies ajustes manuales de Netlify: netlify.toml define el comando y la carpeta de publicación.

Después de subirlos, espera a que Netlify muestre "Published".
